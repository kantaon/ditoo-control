# Changelog

## [1.0.0] – 2026-11-08

First public release.

### Highlights
- **Automatic mode** – the display follows what you do: overheating alerts, notifications, AI agents, games, pomodoro, idle rotation.
- **Gaming HUD** – FPS, CPU | GPU temperature and a 16-second frame-time graph; still images updated in place, no flicker.
- **Claude Code & Codex** – distinct signs for each agent (working, waiting for you, done, error); one-click setup that backs up and chains existing configs.
- **25 hand-tuned scenes** – animated clock, weather (rain, snow, sun, storm, fog, night), pomodoro, overheating, notifications and six ambient effects.
- **Works without extra tools** – CPU load, GPU load and NVIDIA GPU temperature are read directly; the optional MSI Afterburner adds CPU temperature and the optional RivaTuner adds FPS. The app shows their status and download links; the installer offers WebView2 if it is missing.
- **Desktop app** – setup wizard, live display preview with "what you see" legend, tooltips, help page, scene gallery, English and Czech.
- **Sounds** – 8-bit jingles from the Ditoo speaker without changing your default audio output; silent while gaming and at night.
- **Hotkeys** – Ctrl+Shift+Alt+A/D/S/W, context-aware, 60 % keyboard friendly.
- **Saves the Ditoo battery** – Off mode really switches the LEDs off, the display goes dark when you're away or lock the PC, night brightness can go down to 0; reconnects on its own after recharging.
- **Light on resources** – below-normal priority, EcoQoS, zero work while the window is hidden.
- **Installer** – per-user setup with Start menu entry and optional autostart; portable zip.
